# BORROWED TIME — Training → Forgotten City → The Last Seed

เพิ่มฉากภายในโรงงานด่าน 3 ในโปรเจกต์ AFO บน Unity 6000.3.25f1 / URP 17.3 และเชื่อมเส้นทางจากด่านเมือง

## เปิดเล่น

เปิด `Assets/_BorrowedTime/Scenes/TrainingArea.unity` แล้ว Play → Enter เพื่อเริ่มการเดินทางครบสามด่าน

รับเมล็ดพันธุ์จาก Norman ในด่านฝึก จากนั้นเกมจะโหลดเมืองอัตโนมัติ เมื่อแก้ปริศนาเมืองและเดินผ่านประตูโรงงาน เกมจะโหลด `FactoryInterior` พร้อมเมล็ด พลังงาน และผลการฟื้นสวนทางเลือก

เปิด `Assets/_BorrowedTime/Scenes/FactoryInterior.unity` ตรงจาก Editor เพื่อดูฉากและทดลองปริศนาได้ แต่จะปลูกเมล็ดจนจบไม่ได้หากยังไม่เคยรับเมล็ดจริงจากด่านแรก UI จะแจ้งสถานะนี้

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| WASD / เมาส์ | เดิน / หมุนกล้อง |
| Shift / Space | วิ่ง / กระโดด |
| RMB ค้าง + ล้อเมาส์ถอยเข้าหาตัว | คืนสภาพ / Rewind หนึ่งสถานะ |
| RMB ค้าง + ดันล้อเมาส์ไปหน้า | เร่งสภาพ / Accelerate หนึ่งสถานะ |
| RMB ค้าง + LMB ค้าง | ดูดพลังจากพืชในระยะ 3 เมตร |
| F | ใช้แผงควบคุม วาล์ว ลิฟต์ และปลูกเมล็ด |
| H / Tab | ขอคำใบ้ / ดูภาพรวมด่าน |
| R | เริ่มด่านปัจจุบันใหม่ |
| Esc / F2 | พัก / ซ่อน UI |

เปลี่ยนสภาพใช้พลัง 15 ต่อขั้น มีคูลดาวน์ 0.5 วินาที การปลูกเมล็ดใช้ 30 และเร่งการเติบโตอีกสองขั้นใช้รวม 30 พืชฟื้นพลังเองและไม่ถูกดูดต่ำกว่า 20% เมล็ดพันธุ์วิเศษไม่อนุญาตให้ดูดพลัง

## ด่านโรงงานตามจุดหลักในภาพอ้างอิง

1. **โถงรับสินค้า:** สำรวจทางเข้าและพืชในกระถางสำหรับเติมพลัง
2. **โถงควบคุมเบื้องต้น:** คืนสภาพแผงหลักและรีเลย์สีฟ้าสองจุด แล้วกด F หน้าแผงเพื่อเปิดประตู รีเลย์เป็นวงจรที่ซ่อมได้ ไม่ใช่แหล่งพลังชีวิต
3. **ระบบลำเลียง:** คืนสภาพสะพานที่ขาดสองขั้น แล้วเดินข้ามไปโถงวัตถุดิบ
4. **โถงวัตถุดิบและลิฟต์:** คืนสภาพแผงลิฟต์ ยืนกลางแท่นแล้วกด F แท่นจะพาผู้เล่นขึ้นจริงจากระดับ 0 ไป 6
5. **ลานสายพาน:** เร่งสภาพตัวควบคุมสองขั้น ลังจะย้ายไปช่องพัก ใช้แผงควบคุมเปิดทางเข้าห้องหม้อไอน้ำ
6. **หม้อไอน้ำ:** คืนสภาพทั้งสามใบให้สมบูรณ์ แล้วกด F ที่แผงระบายแรงดันเพื่อเปิดห้องพลังงาน
7. **ห้องพลังงานและสะพานวงแหวน:** เร่งตัวเชื่อมวงจรสองขั้น แล้วกด F จ่ายไฟ สะพานจริงจะเปิดให้ข้ามไปห้องควบคุม
8. **ห้องควบคุมหลัก:** ปิดวาล์วสามจุด คืนสภาพแผงแกนมลพิษ กด F เพื่อหยุดการปล่อยมลพิษ แล้วใช้แผงน้ำสะอาดอีกจุด แสงแกนกลางและน้ำจะแสดงสถานะหลังแก้ต้นเหตุ
9. **ห้องแกนกลาง:** ใช้ลิฟต์ขึ้นระดับ 12 เติมพลัง ปลูกเมล็ดด้วย F แล้วเล็งผลึกต้นไม้และเร่งสภาพสองขั้นจนเติบโตสมบูรณ์

มีทางเลือกฟื้นโรงเพาะกล้าบนชั้นบนก่อนปลูกเมล็ด โดยคืนสภาพจากเหี่ยวเฉาเป็นแข็งแรง

## ฉากจบ

- **Hopeful Renewal / ความหวังผลิบาน:** ฟื้นสวนเล็กในด่านเมือง และฟื้นโรงเพาะกล้าในโรงงาน ต้นไม้เติบโตและพื้นที่สีเขียวขยายรอบห้องปลูก
- **Fragile Tomorrow / วันพรุ่งนี้ที่เปราะบาง:** ทำทางเลือกไม่ครบทั้งสองจุด ยังคงหยุดโรงงานและปลูกต้นไม้สำเร็จ แต่ข้อความและภาพการฟื้นฟูแสดงว่าบางพื้นที่ยังต้องดูแลต่อ

ทั้งสองแบบเป็นการจบเกมตามภารกิจหลัก ระบบไม่ให้ปลูกหากยังมีมลพิษ ไม่มีน้ำสะอาด ไม่มีเมล็ด หรือมีพลังไม่พอ เมล็ดถูกใช้เพียงครั้งเดียว

## การรีเซ็ตและขอบเขต

R ในโรงงานจะรีเซ็ตเครื่องจักร ลิฟต์ และความคืบหน้าของโรงงาน พร้อมคืนสถานะเมล็ดและพลังงานที่นำเข้ามาในด่านนั้น จึงทดลองทางเลือกฉากจบอีกแบบได้ ข้อมูลสวนทางเลือกจากเมืองยังอยู่

ข้อมูลข้ามซีนเก็บในหน่วยความจำของการเล่นครั้งนี้ ยังไม่ได้เพิ่มระบบเซฟลงดิสก์

งานฉาก ตัวละคร แอนิเมชันของเครื่องจักร ควัน และเอฟเฟกต์ยังเป็นต้นแบบตามที่ตกลงไว้ ไม่มีการดาวน์โหลด asset ใหม่ และยังไม่ได้ส่งออก Windows build หรือวัดประสิทธิภาพบนเครื่องอื่น

## ไฟล์และเครื่องมือสร้างฉาก

- `Scripts/BTFactoryGame.cs`: ลำดับปริศนา ประตู วาล์ว การปลูก และฉากจบ
- `Scripts/BTFactoryLift.cs`: แท่นลิฟต์ที่เคลื่อนและพาผู้เล่นขึ้นจริง
- `Scripts/BTJourney.cs`: ข้อมูลเมล็ด พลังงาน ทางเลือก และการเปลี่ยนซีน
- `Editor/BTFactoryBuilder.cs`: เมนู `Tools > Borrowed Time > Build Factory Interior`
- `Editor/BTFullGamePlaytest.cs`: ตัวทดสอบสามด่านและฉากจบสองแบบ ไม่รวมใน build

หากนำแพ็กเกจไปใช้กับโปรเจกต์อื่น ให้ติดตั้ง URP, Input System และ uGUI แล้วเลือก `Tools > Borrowed Time > Register journey scenes` ก่อนเล่นจากฉาก TrainingArea ใน AFO รอบนี้เพิ่มฉากไว้แล้ว โดยคงรายการฉากเดิมของโปรเจกต์ไว้

ดู `FullGamePlaytest.txt` สำหรับผลทดสอบจริง เวลาของตัวทดสอบไม่ใช่เวลาเล่นครั้งแรกของผู้เล่นใหม่
