# Seven temporal puzzle categories — approved user specification

User supplied all seven categories on 2026-10-24 and approved irreversible
choices affecting OPTIONAL exploration/rewards only, never the main ending.
Implement a separate BT_ForestPuzzleTrail beside Claude's forest main route.
Reuse installed assets; clearly named greybox structures are mechanical prototypes,
not new final models. No packages, purchases, scene reset or character integration.

1. State change: new/rotted timber and sound/eroded stone; keep uncommon.
2. Growth as structure: seed/sapling/tree, extendable climb vine, mushroom step.
3. Lifecycle switch: grown glowing flower lights a dark passage; fallen leaves
   reveal a secret opening.
4. Water: restore a local floodgate to float a log crossing, or drain to walk the
   bed. Both traversals must physically exist.
5. Animal tool: restore a nursery tree, an installed Chicken bird carries seed
   along an authored route to an unreachable shelf, drops it and a plant grows.
   Chicken is a prototype substitute for a flying bird, not a custom flying model.
6. Chain: age shade tree A, light reaches B, B naturally grows once and pushes
   a rock. No repeated natural-growth energy farming.
7. Reverse reasoning: direct repair gives a short misaligned span; collapse
   before repairing to build the right span. A separate optional three-way
   choice has one shared physical brace, consumes it on commitment, locks other
   optional routes. An explicitly optional exhaustible support can be lost by
   full extraction; other sources and the main keystone remain available.

Generic TimeTarget gains a runtime-only public interaction lock for committed
choices. PlayerController gains bounded vine climbing (W/S, Space to release)
using an explicit climb region; no teleport and no global input replacement.
One stored-time meter and the existing E extraction / Q spending remain.

Verification: each category's live state/physics consequence; initial state and
event ordering; release mid-age; natural growth once and no energy mutation;
choice exactly one and no core lock; water dry and floating traversals; climb
region scales with growth. Native keyboard feel and final art remain human QA.
