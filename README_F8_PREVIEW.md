# F8 – Borrowed Time preview

- ด่านฝึก: กด F8 เพื่อข้ามไปเมือง พร้อมเมล็ดพันธุ์
- เมือง: กด F8 เพื่อข้ามไปโรงงาน พร้อมเมล็ดพันธุ์และระบบน้ำที่ฟื้นแล้ว
- โรงงาน: กด F8 เพื่อดูฉากจบเกมและคัตซีนโลกเริ่มฟื้นตัว
- ระหว่างคัตซีน: กด F8 อีกครั้งเพื่อไปหน้าผลลัพธ์
- หน้าผลลัพธ์: กด F8 เพื่อกลับเข้าโรงงานพรีวิวรอบใหม่

เข้าโรงงานตรงจากเมนู Unity: Tools > Borrowed Time > Factory > Open factory preview with F8

โหมดพรีวิวมีพลังเริ่มต้น 100 และไม่เขียนทับเซฟเดิม รวมถึงสถานะปริศนาเมืองที่เก็บใน PlayerPrefs การ Continue เซฟหรือเริ่ม New Journey จะออกจากโหมดพรีวิว

รายงานตรวจ: Captures/TrainingComfort/FactoryRoutes/F8Preview.txt และ ManualFactoryRoute.txt
