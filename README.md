# AFO / Wobble Works Graybox

Unity version: 6000.3.25f1

## Open the playable scene

1. Pull the latest main branch.
2. Open the repository folder in Unity Hub with Unity 6000.3.25f1.
3. Wait for asset import and script compilation to finish.
4. In the Project window, open Assets/WobbleWorks/Scenes/WobbleGreybox01.unity.
5. Press Play. SampleScene is the template scene, not the Graybox game.

Pulling Git changes does not switch the scene currently open in Unity.
The build scene list points to WobbleGreybox01.
If Play is blocked, check the Console for compilation errors.

## Controls

WASD: move. Mouse: look. E: hold to absorb. F: property action.
Space: jump / property action. Tab: overview.

## Team workflow

Pull before starting work. Commit and push after saving your scene and assets.
Use separate branches for changes and coordinate before editing the same scene.
Keep .meta files together with their assets.
