# คอมโบ 15 คู่ — กติกาปัจจุบัน

เจ้าของยืนยันวันที่ 2026-10-23 ให้ทุกพลังผสมกันได้ครบ แต่ตัดหลัก/เสริมและผลตามลำดับออก
มี 6 พลังและ 15 คู่ ไม่ใช่ 30 ช่อง น้ำ+ไฟฟ้าให้ผลเดียวกับไฟฟ้า+น้ำ

- F: ใช้พลังเดี่ยวที่เลือก
- Q: เปลี่ยนพลังเดี่ยวที่เลือก โดยไม่เปลี่ยนคอมโบ
- G: ใช้พลังผสมของสองพลังที่ถือ
- SPACE: กระโดด/ชาร์จเด้งตามเดิม; E ดูด; J สมุดพลัง
- ปืนแม่เหล็ก: G ค้างดูดแล้วปล่อยยิง หรือถือโลหะด้วย F แล้วกด G

| คู่พลัง | ผลเดียวของคู่นี้ |
|---|---|
| แม่เหล็ก + แรงดัน | ปืนแม่เหล็ก ยิงโลหะที่ถือ |
| แม่เหล็ก + เด้ง | สลิงแม่เหล็ก ดึงตัวเข้าหาจุดโลหะ |
| แม่เหล็ก + น้ำ | สายน้ำแม่เหล็ก ลากโลหะ/แพเข้าหาตัว |
| แม่เหล็ก + ไฟฟ้า | แม่เหล็กไฟฟ้า ช่วยยกของหนักถึง 40 กก. ชั่วคราว |
| แม่เหล็ก + ความร้อน | ความร้อนเหนี่ยวนำ ทำโลหะที่เล็งให้ร้อน |
| แรงดัน + เด้ง | ลูกลมกระดอน ยิงสวิตช์หลังมุม |
| แรงดัน + น้ำ | น้ำแรงสูง ยิงไกลและผลักของ |
| แรงดัน + ไฟฟ้า | สายฟ้าแรงสูง ยิงไกลและกระจายได้สามเป้า |
| แรงดัน + ความร้อน | พ่นไฟระยะไกล |
| เด้ง + น้ำ | ลูกน้ำเด้ง ส่งน้ำข้ามกำแพง |
| เด้ง + ไฟฟ้า | สายฟ้าชิ่ง ต่อสวิตช์ได้สี่เป้า |
| เด้ง + ความร้อน | ลูกไฟเด้ง จุดเตาหรือละลายน้ำแข็ง |
| น้ำ + ไฟฟ้า | สายน้ำไฟฟ้า จ่ายไฟผ่านน้ำ |
| น้ำ + ความร้อน | ไอน้ำ ยกตัวและป้อนเครื่องไอน้ำ |
| ไฟฟ้า + ความร้อน | เชื่อมไฟฟ้า ซ่อมรางและละลายฟิวส์ |
